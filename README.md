作品規格書：研究生的兩難

作品概念與目標

本作品是一個以研究生生活與學術研究為題材的二選一互動遊戲。玩家面對研究方向、指導方式、合作關係與時間安排等情境，在兩個各有利益與代價的選項中做出決定。

作品希望讓玩家產生「兩邊都想選，但又各有顧慮」的取捨感，並透過選後結局，想像不同決定可能帶來的影響。完成遊戲後，系統將本輪選擇整理成六維研究人格圖，讓玩家回顧自己的研究偏好。

主要使用對象為研究生、大學生，以及對研究生活有興趣的人。題目應提供足夠背景，讓沒有研究所經驗的玩家也能理解。

題庫內容

遊戲共包含30題，分成三種語氣，各10題，交錯出現：

學術苦笑：以研究生活中容易產生共鳴的困擾為主。
研究取捨：呈現研究工作中不同做法的利益與代價。
荒謬學術：加入想像或誇張設定，增加趣味。

每道題目須包含題目名稱、共同情境、兩個選項、各選項的利益與代價，以及選擇後的具體結局。

兩個選項必須建立在同一個情境下，避免因前提不同而無法比較。選項不設定標準答案，也不刻意將其中一方寫成明顯正確或毫無吸引力的選擇。結局以第二人稱描述選擇帶來的後續情況，讓玩家能清楚連結自己的決定與結果。

使用流程

玩家開啟網頁後，直接進入第一題。畫面顯示題數、題目情境、左右兩個插畫選項，以及中央可拖曳的紙飛機。

玩家完成選擇後，畫面聚焦所選場景，顯示選擇名稱與對應結局。此時可以按「重新選擇」返回當前題目的選項畫面，或按「下一個兩難」繼續。

第30題作答後，下一步按鈕改為「看看我的研究人格」，進入結果畫面。玩家可以查看六維圖、人格解析與各面向的作答依據，也可以按「再玩一次」重新開始。

操作與互動規則

拖曳作答：將紙飛機拖入左側或右側選項區，放開時才提交答案；拖曳途中可改變方向。

取消拖曳：在選項區外放開、按Escape、指標操作被取消或視窗失去焦點時，取消拖曳，不記錄答案。

點選作答：點擊任一選項的文字或插畫區域，可選擇該選項。

鍵盤作答：在尚未作答時，按1選擇左側、按2選擇右側；快捷鍵不得干擾文字輸入。

結局揭曉：只顯示目前選擇的結局，不同時展示另一個選項的結果。

重新選擇：撤回當前題目的答案與計分，恢復兩個選項；重新作答後依新答案計分。

前進：尚未作答時不能進入下一題；每次前進只移動一題。

防止重複操作：同題不能重複提交；轉場期間暫停作答、改選與前進，避免連按造成跳題。

重玩：清空本輪答案與人格結果，返回第一題，保留日夜模式偏好。

動畫結束或發生中斷時，操作控制必須恢復，不能讓玩家停在無法繼續的狀態。

六維研究人格與計分

每道題目對應一個主要研究面向，每個面向各有5題。六個面向及其兩端偏好如下：

探索：熟悉路線／未知問題
自主：密集指導／自行判斷
協作：獨立專注／共同推進
求證：快速試行／反覆驗證
表達：安靜累積／公開交流
節奏：集中衝刺／穩定續航

每題的兩個選項分別對應該面向的兩端。選項放在左側或右側，不直接決定計分方向。

完成作答後，各面向以「選擇右欄偏好的次數 ÷ 該面向題數 × 100」計算分數。雷達圖越靠外，代表越偏向右欄的做法；越靠內，代表越偏向左欄。兩端沒有優劣，也不代表能力高低。40至60分解讀為兩種做法並用。

系統依各面向偏離中點的程度，產生主要人格稱號，並搭配另一個明顯偏好補充解析。結果畫面須包含：

六維研究偏好雷達圖。
人格稱號與主要偏好說明。
不同偏好之間的組合解析。
一項與本輪結果相關的研究建議。
六個可展開的面向說明，以及來自本輪實際作答的例子。

結果只能引用玩家本輪的選擇，不得虛構作答紀錄或其他玩家的比較資料。畫面須說明這是遊戲內的偏好解讀，不是心理測驗或能力評分。

介面與視覺設計

介面以題目、選項與玩家的選擇為主要焦點，使用紙飛機、插畫與留白呈現研究生活的情境。避免加入與遊玩無關的開發評分、回饋表單、統計表及重複說明。

選項畫面應讓左右兩側具有相近的視覺份量。作答後，透過場景集中、清楚的標題與較大的結局文字，突出玩家自己的決定。

右上角設置單一月亮／太陽圖示按鈕，切換日間與夜間模式。兩種模式都須維持文字、背景與操作提示的可辨識度。

字體使用依SIL Open Font License 1.1授權的更紗UI TC，保留必要的版權與授權資訊。將本作使用的字形內嵌於成品，讓玩家不需安裝字體，也能在離線狀態下閱讀。

版面以桌面操作為主，同時支援最小320px寬的窄版畫面。題目、選項、結局、圖表與按鈕不得出現水平溢出或互相遮擋。

動畫與無障礙操作

動畫應協助玩家理解操作與狀態變化，包含選項互動回饋、紙飛機移動、結局揭曉、換題、日夜圖示切換及按鈕按壓。

六個研究面向的細節須能平順展開與收合，「＋／－」圖示同步變化。快速連續點擊時，畫面應回應最後一次操作，不能停在內容被裁切或無法開關的狀態。

當系統啟用「減少動態效果」時，介面應省略非必要動畫並直接呈現操作結果。不支援部分動畫效果的瀏覽器，仍須保有基本作答與細節開關功能。

主要操作須能使用鍵盤完成，並提供可辨識的焦點提示。換題時，輔助技術應能取得題數、題目情境與左右選項；作答後應能取得所選結局。圖表也須提供文字說明，不能只依賴圖形或顏色傳達結果。

技術與資料保存

最終成品須整理成單一index.html，將CSS、JavaScript、插畫與所需字型包含在檔案內。玩家可直接用瀏覽器開啟，不需安裝套件、登入帳號或呼叫外部API。

開發時可將題庫、遊戲狀態、人格計分與介面分開維護，再合成單一HTML，以便修改與驗證。

作答資料只保留在本次頁面的記憶體中，重新整理或重玩時清除。日夜模式偏好可保存在瀏覽器本機；即使無法儲存偏好，也不能影響遊戲操作。

作品不蒐集個人資料、不上傳玩家答案，也不提供真實玩家票數或即時AI生成功能。

驗收條件

作品完成時，應符合以下條件：

單一index.html可直接開啟並操作，沒有必須另外下載的執行資源。
玩家能依序完成30題，題數與作答狀態正確。
拖曳、點選與鍵盤作答都能得到相同結果。
取消拖曳不會留下答案，連續操作不會造成重複計分或跳題。
選後只呈現所選結局，重新選擇後能正確更新答案與計分。
完成遊戲後產生六維圖與解析，所引用的例子符合本輪作答。
六個面向的細節可正常展開、收合，並支援鍵盤與減少動態效果設定。
重玩後回到第一題，不保留上一輪答案或人格分數。
日夜模式均可閱讀，桌面與窄版畫面沒有文字遮擋或水平溢出。
透過GitHub Pages公開後，未登入GitHub的使用者也能開啟並遊玩。
